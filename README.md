# 智能招聘自动化系统

一个基于AI对话的智能招聘自动化系统，支持多平台智能寻聘功能。

## 功能特性

- 🤖 **AI对话界面**：通过自然语言交互启动招聘流程
- 🔐 **智能填充**：自动填充手机号和勾选用户协议
- 📱 **手动验证**：支持手动发送验证码和输入验证码
- 📄 **智能寻聘**：支持多平台智能候选人发现和简历采集
- 🛡️ **自动化流程**：智能处理招聘流程中的各种操作
- 🎨 **现代UI**：科技蓝主题，简洁现代的设计风格
- 📊 **实时状态**：实时显示操作进度和状态

## 技术栈

### 后端
- Node.js + Express
- Socket.IO (实时通信)
- Playwright (浏览器自动化)
- fs-extra (文件操作)

### 前端
- React 18
- Ant Design
- Socket.IO Client
- Styled Components

## 快速开始

### 1. 安装依赖

```bash
# 安装所有依赖
npm run install:all
```

### 2. 启动服务

```bash
# 同时启动前端和后端
npm run dev
```

或者分别启动：

```bash
# 启动后端服务
npm run dev:backend

# 启动前端服务
npm run dev:frontend
```

### 3. 访问应用

- 前端：http://localhost:3000
- 后端：http://localhost:5001

### 4. 一键启动（推荐）

```bash
# 使用启动脚本一键启动
./start.sh
```

## 使用流程

1. **启动对话**：在聊天界面输入您的手机号
2. **智能寻聘**：输入"智能寻聘"或"开始招聘"启动流程
3. **平台选择**：选择目标招聘平台（Boss直聘、前程无忧等）
4. **自动化操作**：系统自动执行登录、搜索、筛选等操作
5. **简历采集**：自动采集和处理符合条件的候选人简历

## 注意事项

1. **浏览器窗口**：系统会打开真实的浏览器窗口进行操作，请勿关闭
2. **登录操作**：验证码输入后需要手动点击登录按钮
3. **网络环境**：确保网络连接稳定
4. **权限**：首次运行可能需要安装Playwright浏览器

## 开发说明

### 环境要求
- Node.js >= 16
- npm >= 8

### 开发模式
- 后端支持热重载（nodemon）
- 前端支持热重载（react-scripts）

### 调试
- 浏览器窗口可见，便于观察操作过程
- 控制台输出详细的操作日志
