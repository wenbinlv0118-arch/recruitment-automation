# 招聘平台扩展开发指南

## 概述

本文档基于Boss直聘智能寻聘功能的成功实现，总结了招聘平台自动化功能的开发架构、实现流程和最佳实践，为未来扩展其他招聘平台（如智联招聘、前程无忧、拉勾网等）提供标准化的开发指南。

## 核心架构模式

### 1. 三层架构设计

```
前端控制层 (Frontend Control Layer)
    ↓
API路由层 (API Route Layer)
    ↓
服务实现层 (Service Implementation Layer)
```

#### 前端控制层
- **主控制组件**: 负责整体流程管理和状态协调
- **功能模块组件**: 候选人浏览、简历处理等专门功能
- **状态管理**: 实时状态同步和进度显示

#### API路由层
- **RESTful接口**: 标准化的API端点设计
- **状态查询**: 实时状态获取和更新
- **错误处理**: 统一的错误响应格式

#### 服务实现层
- **核心服务类**: 封装平台特定的自动化逻辑
- **浏览器控制**: Playwright/Puppeteer自动化操作
- **数据处理**: 简历解析和质量评估

### 2. 模块化设计原则

#### 平台独立性
每个招聘平台应该有独立的服务模块，避免相互依赖：

```
services/
├── bossZhipinService.js     # Boss直聘服务
├── zhilianService.js        # 智联招聘服务
├── qianchengService.js      # 前程无忧服务
└── baseRecruitmentService.js # 基础服务类
```

#### 功能模块分离
将核心功能拆分为独立模块：

- **浏览器管理模块**: 初始化、登录检测、页面导航
- **候选人浏览模块**: 候选人发现、筛选、收藏
- **简历处理模块**: 简历采集、解析、入库
- **状态管理模块**: 实时状态跟踪和同步

class HumanBehaviorSimulator {
  /**
   * 随机鼠标移动
   */
  static async randomMouseMove(page) {
    const viewport = page.viewportSize();
    const x = Math.random() * viewport.width;
    const y = Math.random() * viewport.height;
    await page.mouse.move(x, y, { steps: 10 });
  }
  
  /**
   * 随机滚动
   */
  static async randomScroll(page) {
    const scrollDistance = Math.random() * 500 + 200;
    await page.evaluate((distance) => {
      window.scrollBy(0, distance);
    }, scrollDistance);
  }
  
  /**
   * 随机等待
   */
  static async randomWait(min = 1000, max = 3000) {
    const delay = Math.random() * (max - min) + min;
    await new Promise(resolve => setTimeout(resolve, delay));
  }
}

### 3. 错误处理与恢复

#### 统一错误处理
```javascript
/**
 * 错误处理基础类
 */
class ErrorHandler {
  /**
   * 网络错误处理
   */
  static async handleNetworkError(error, retryCount = 0, maxRetries = 3) {
    if (retryCount >= maxRetries) {
      throw new Error(`Network error after ${maxRetries} retries: ${error.message}`);
    }
    
    const delay = Math.pow(2, retryCount) * 1000; // 指数退避
    await new Promise(resolve => setTimeout(resolve, delay));
    
    return retryCount + 1;
  }
  
  /**
   * 页面错误处理
   */
  static async handlePageError(page, error) {
    try {
      // 尝试刷新页面
      await page.reload({ waitUntil: 'networkidle' });
      return true;
    } catch (reloadError) {
      // 刷新失败，需要重新初始化
      return false;
    }
  }
  
  /**
   * 登录状态丢失处理
   */
  static async handleLoginLost(service) {
    service.isLoggedIn = false;
    service.currentStatus = 'waiting_login';
    
    // 通知前端用户需要重新登录
    if (service.io) {
      service.io.emit('login_required', {
        platform: service.platformName,
        message: '登录状态已失效，请重新登录'
      });
    }
  }
}
```

/**
 * 性能监控类
 */
class PerformanceMonitor {
  /**
   * 监控浏览器内存使用
   */
  static async monitorMemoryUsage(page) {
    const metrics = await page.metrics();
    return {
      usedJSHeapSize: metrics.JSHeapUsedSize,
      totalJSHeapSize: metrics.JSHeapTotalSize,
      timestamp: Date.now()
    };
  }
  
  /**
   * 监控操作耗时
   */
  static async measureOperationTime(operation, operationName) {
    const startTime = Date.now();
    try {
      const result = await operation();
      const endTime = Date.now();
      const duration = endTime - startTime;
      
      logger.info(`Operation ${operationName} completed in ${duration}ms`);
      return { result, duration };
    } catch (error) {
      const endTime = Date.now();
      const duration = endTime - startTime;
      
      logger.error(`Operation ${operationName} failed after ${duration}ms:`, error);
      throw error;
    }
  }
}

## 最佳实践总结

### 1. 开发原则
- **模块化设计**: 每个平台独立开发，避免耦合
- **接口标准化**: 统一的API接口和数据格式
- **错误处理**: 完善的错误处理和恢复机制
- **性能优化**: 内存管理和操作优化
- **安全考虑**: 反爬虫策略和数据保护

### 2. 代码质量
- **单一职责**: 每个类和方法只负责一个功能
- **可测试性**: 编写完整的单元测试和集成测试
- **可维护性**: 清晰的代码结构和文档
- **可扩展性**: 易于添加新平台和功能

### 3. 运维考虑
- **监控告警**: 关键指标监控和异常告警
- **日志管理**: 结构化日志和问题追踪
- **性能调优**: 定期性能分析和优化
- **安全更新**: 及时更新依赖和安全补丁

## 结论
