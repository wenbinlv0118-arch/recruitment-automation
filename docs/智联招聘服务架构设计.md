# 智联招聘服务架构设计文档

## 架构概述

智联招聘服务架构基于Boss直聘的成熟架构模式，采用相同的技术栈和设计模式，确保功能独立性的同时保持系统一致性。

## 核心设计原则

### 1. 架构独立性
- **独立服务类**：ZhilianService 完全独立于 BossZhipinService
- **独立路由**：单独的 API 路由文件，避免功能耦合
- **独立配置**：专门的配置文件和筛选条件
- **独立状态管理**：独立的浏览状态和简历处理状态

### 2. 功能复用性
- **共享基础设施**：复用 Playwright 浏览器自动化框架
- **共享数据模型**：使用相同的简历数据结构和存储格式
- **共享工具函数**：复用日志、错误处理等工具模块
- **共享前端组件**：复用筛选面板、状态显示等通用组件

### 3. 扩展性设计
- **模块化架构**：便于后续添加前程无忧等其他平台
- **配置驱动**：通过配置文件控制不同平台的行为
- **插件化设计**：支持平台特定功能的插件扩展

### 1. ZhilianService 服务类

```javascript

    };
    
    // 简历处理状态跟踪
    this.resumeProcessingStatus = {
      isActive: false,
      resumes: [],
      processingCount: 0,
      completedCount: 0,
      currentIndex: 0,

```

**核心功能方法**：
- `initializeBrowser()` - 浏览器初始化
- `openZhilianWebsite()` - 打开智联招聘网站
- `checkLoginStatus()` - 检查登录状态
- `executeBrowsingTask()` - 执行候选人浏览任务
- `searchCandidates()` - 搜索候选人
- `extractResumeContent()` - 提取简历内容
- `processResumeDownload()` - 处理简历下载

## 智联招聘特定功能

### 1. 网站导航流程
- 打开智联招聘企业版网站
- 自动导航到简历搜索页面
- 处理登录验证（手机验证码或扫码）
- 进入简历库管理界面

### 2. 简历搜索与筛选
- 支持关键词搜索
- 学历、经验、薪资等条件筛选
- 地区、行业等高级筛选
- 自动翻页和结果收集

### 3. 简历下载与处理
- 批量简历下载
- 简历格式解析（Word、PDF）
- 简历质量评估
- 自动入库和分类

### 4. 智能筛选功能
- 基于JD匹配度评分
- 关键技能匹配分析
- 工作经验相关性评估
- 薪资期望匹配度

## 数据流设计

### 1. 候选人浏览流程
```
用户启动 → 初始化浏览器 → 打开智联招聘 → 检查登录状态 
    ↓
配置筛选条件 → 执行搜索 → 获取候选人列表 → 逐个处理候选人
    ↓
提取简历信息 → 质量评估 → 下载简历 → 解析入库 → 更新状态
```

### 2. 实时状态同步
```
ZhilianService → Socket.IO → 前端组件 → 状态更新 → UI刷新
```

### 3. 错误处理流程
```
异常捕获 → 错误分类 → 重试机制 → 降级处理 → 用户通知
```

## 风险评估

### 技术风险
- **网站结构变化**：智联招聘网站改版可能影响自动化脚本
- **反爬虫机制**：可能遇到验证码、频率限制等反爬虫措施
- **性能问题**：大量数据处理可能导致性能瓶颈

### 业务风险
- **合规性问题**：需要确保符合智联招聘的使用条款
- **数据质量**：简历数据质量可能影响筛选效果
- **用户体验**：自动化过程中的异常可能影响用户体验

### 缓解措施
- 定期更新和维护自动化脚本
- 实施完善的错误处理和重试机制
- 建立监控告警系统
- 制定应急响应预案
