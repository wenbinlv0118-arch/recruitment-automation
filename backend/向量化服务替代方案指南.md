# 🚀 向量化服务替代方案指南

## 📋 概述

由于无法获得 Hugging Face API 密钥，我们为您提供了多种便捷的文本向量化替代方案，无需依赖外部 API 即可实现高质量的文本向量化和相似度检索。

## 🎯 可用的向量化方案

### 1. **轻量级向量化服务** (推荐)
- **特点**: 纯 JavaScript 实现，无需外部依赖
- **算法**: 基于 TF-IDF 和中文分词
- **优势**: 快速、轻量、无网络依赖
- **适用场景**: 生产环境、快速原型开发

### 2. **本地模型向量化**
- **特点**: 使用 `@xenova/transformers` 本地运行模型
- **算法**: 基于 Sentence Transformers
- **优势**: 高质量向量化，无需 API 密钥
- **适用场景**: 需要高精度向量化的场景

### 3. **模拟模式向量化**
- **特点**: 基于关键词匹配的轻量级方案
- **算法**: 哈希函数 + 关键词匹配
- **优势**: 极快速度，最小资源消耗
- **适用场景**: 快速测试、资源受限环境

## 🔧 快速开始

### 1. 安装依赖

```bash
cd backend
npm install
```

### 2. 配置环境变量

在 `.env` 文件中配置：

```bash
# 向量化配置
VECTORIZATION_MODE=lightweight
USE_LOCAL_MODEL=false
HUGGINGFACE_API_KEY=your_huggingface_api_key_here
```

### 3. 使用向量化服务

```javascript
const VectorServiceSelector = require('./src/services/vectorServiceSelector');

// 创建服务选择器（自动选择最佳方案）
const vectorService = new VectorServiceSelector();

// 文本向量化
const embedding = await vectorService.getEmbeddings('招聘前端开发工程师');

// 批量向量化
const embeddings = await vectorService.getEmbeddings([
  '招聘前端开发工程师',
  '需要React和Vue.js经验',
  'Python后端开发岗位'
]);

// 存储文档向量
await vectorService.storeDocumentVectors(textChunks, 'doc-1', {
  title: '招聘文档',
  category: '技术岗位'
});

// 相似度检索
const results = await vectorService.retrieveSimilar('前端开发', 5);

// 混合搜索
const hybridResults = await vectorService.hybridSearch('前端开发', 5);
```

## 🔄 迁移指南

### 从 Hugging Face API 迁移

1. **更新环境变量**:
```bash
# 使用轻量级服务
VECTORIZATION_MODE=lightweight
USE_LOCAL_MODEL=false

# 或使用本地模型
VECTORIZATION_MODE=local
USE_LOCAL_MODEL=true
```

2. **更新代码**:
```javascript
// 旧代码
const VectorService = require('./src/services/vectorService');
const vectorService = new VectorService();

// 新代码
const VectorServiceSelector = require('./src/services/vectorServiceSelector');
const vectorService = new VectorServiceSelector();
```

3. **验证迁移**:
```bash
node test-vector-selector.js
```

## 📈 性能优化建议

### 1. **批量处理**
- 尽量使用批量向量化而不是单个处理
- 一次性存储多个文档块

### 2. **内存管理**
- 定期清理不需要的向量数据
- 监控内存使用情况

### 3. **缓存策略**
- 对重复查询进行缓存
- 使用 Redis 等外部缓存

### 4. **异步处理**
- 使用异步方式避免阻塞主线程
- 实现队列机制处理大量请求
