## 📞 支持联系

如果在验收过程中发现问题：

1. **查看故障排除指南**：`deploy/docs/zeabur-troubleshooting.md`
2. **运行诊断脚本**：`./deploy/scripts/check-deployment-status.sh`
3. **查看部署日志**：Zeabur 控制台 → 项目 → 服务 → Logs
4. **联系技术支持**：提供详细的错误信息和日志

记住：系统性的验收测试是确保部署质量的关键步骤！
