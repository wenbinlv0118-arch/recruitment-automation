# 智能复制助手 Chrome 扩展

一个专门解决网页复制问题的Chrome扩展，通过可信的用户事件触发`document.execCommand('copy')`，有效解决`Command+C`复制失败的问题。

## 功能特性

### 🚀 核心功能
- **智能复制机制**: 优先使用现代Clipboard API，失败时自动降级到`document.execCommand('copy')`
- **可信事件触发**: 扩展中的事件被浏览器视为可信，绕过安全限制
- **多种触发方式**: 支持快捷键、按钮点击和弹窗操作
- **实时通知**: 复制成功/失败的即时反馈

### ⌨️ 快捷键支持
- **Mac**: `Command+Shift+C` 触发智能复制
- **Windows/Linux**: `Ctrl+Shift+C` 触发智能复制
- 浮动复制按钮（页面右下角）

### 🎯 适用场景
- 智联招聘等招聘网站的简历复制
- 受保护内容的文本复制
- 复杂页面结构的内容提取
- 任何`Command+C`失效的网页

## 安装方法

### 开发者模式安装

1. **打开Chrome扩展管理页面**
   - 在地址栏输入: `chrome://extensions/`
   - 或通过菜单: 更多工具 → 扩展程序

2. **启用开发者模式**
   - 点击右上角的"开发者模式"开关

3. **加载扩展**
   - 点击"加载已解压的扩展程序"
   - 选择本项目的`chrome-extension`文件夹
   - 点击"选择文件夹"

4. **确认安装**
   - 扩展应该出现在扩展列表中
   - 浏览器工具栏会显示扩展图标

## 使用方法

### 基本操作

1. **访问目标网页**
   - 打开需要复制内容的网页
   - 选中要复制的文本（可选）

2. **触发复制**
   - **快捷键**: 按下`Cmd+Shift+C`（Mac）或`Ctrl+Shift+C`（Windows）
   - **浮动按钮**: 点击页面右下角的复制按钮
   - **扩展弹窗**: 点击工具栏图标，然后点击"立即复制"

3. **查看结果**
   - 成功时会显示绿色通知
   - 失败时会显示红色错误提示

### 扩展设置

点击工具栏的扩展图标可以:
- 启用/禁用扩展功能
- 立即触发复制操作
- 测试扩展功能状态
- 查看快捷键说明

## 技术原理

### 复制策略

扩展采用渐进式降级策略:

1. **现代Clipboard API** (优先)
   ```javascript
   navigator.clipboard.writeText(selectedText)
   ```

2. **document.execCommand** (兜底)
   ```javascript
   document.execCommand('copy')
   ```

### 可信事件机制

- 扩展中的用户交互被浏览器视为可信事件
- 绕过了网页的安全策略限制
- 确保复制操作能够成功执行

### 权限说明

```json
{
  "permissions": [
    "activeTab",      // 访问当前标签页
    "clipboardWrite", // 写入剪贴板
    "storage"         // 存储设置
  ]
}
```

## 开发说明

### 核心组件

1. **Content Script** (`content.js`)
   - 注入到所有网页
   - 监听快捷键和按钮点击
   - 执行实际的复制操作

2. **Background Script** (`background.js`)
   - 处理扩展全局逻辑
   - 管理设置和存储
   - 处理快捷键命令

3. **Popup** (`popup.html` + `popup.js`)
   - 用户控制界面
   - 设置管理
   - 手动触发复制

### 调试方法

1. **查看控制台日志**
   - 按F12打开开发者工具
   - 在Console中查看扩展日志

2. **检查扩展状态**
   - 访问`chrome://extensions/`
   - 点击扩展的"详细信息"
   - 查看错误和日志

3. **调试后台脚本**
   - 在扩展详情页点击"背景页"
   - 打开后台脚本的开发者工具

## 常见问题

### Q: 为什么有时候复制还是失败？
A: 可能的原因:
- 页面没有选中任何内容
- 网页有特殊的安全策略
- 扩展被禁用或未正确加载

### Q: 快捷键不生效怎么办？
A: 检查:
- 扩展是否已启用
- 快捷键是否与其他软件冲突
- 当前页面是否支持扩展运行

### Q: 如何自定义快捷键？
A: 
1. 访问`chrome://extensions/shortcuts/`
2. 找到"智能复制助手"
3. 修改快捷键设置
