🆕 问题2：智能关闭弹窗功能

新增功能：

1. 弹窗类型识别和关闭

模态弹窗：自动识别并关闭 modal、popup、dialog 等弹窗
通知提示：自动关闭 notification、message、toast 等提示
广告弹窗：自动关闭广告、横幅、推广等弹窗
ESC 键处理：使用 ESC 键尝试关闭弹窗

2. 页面跳转跟随

事件监听：监听 framenavigated 事件，检测页面跳转
弹窗重新设置：页面跳转后自动重新设置弹窗处理
状态同步：确保所有操作都在最新页面上执行

3. 页面就绪检查

网络状态：等待页面网络空闲状态
弹窗清理：自动清理页面上的弹窗
稳定性等待：等待页面稳定后再执行操作

🔧 技术实现细节

弹窗处理设置

// 设置弹窗处理 async setupPopupHandling() { // 监听页面弹窗事件 this.page.on('dialog', async (dialog) => { await dialog.dismiss(); // 自动关闭弹窗 }); // 监听新页面打开事件 this.page.on('popup', async (popup) => { await popup.close(); }); // 监听页面跳转事件 this.page.on('framenavigated', async (frame) => { if (frame === this.page.mainFrame()) { await this.setupPopupHandling(); // 重新设置弹窗处理 } }); }

智能弹窗关闭
