# Moirai 能力卡片功能说明

## 功能概述

Moirai 能力卡片功能在"与 Moirai 对话"页面的顶部展示，为用户提供了直观的功能选择界面。用户可以通过点击不同的能力卡片来快速选择 Moirai 的功能，系统会自动生成相应的提示信息，提升用户体验。

## 能力卡片列表

### 1. 智能寻聘 🤖
- **功能描述**: 自动化招聘流程，智能筛选候选人
- **关键词**: 招聘、寻聘、智能招聘、自动化招聘
- **点击后生成**: "我想启动智能寻聘功能，请帮我自动化招聘流程"

### 2. 简历推荐 👤
- **功能描述**: 基于岗位需求推荐优秀候选人
- **关键词**: 简历、候选人、推荐、人才
- **点击后生成**: "我需要简历推荐功能，请帮我推荐合适的候选人"

### 3. 知识检索 🔍
- **功能描述**: 搜索企业文档和知识库资料
- **关键词**: 文档、知识、检索、搜索、查找
- **点击后生成**: "我想搜索企业知识库，请帮我查找相关文档"

### 4. 数据分析 📊
- **功能描述**: 招聘数据统计和分析报告
- **关键词**: 数据、分析、统计、报告
- **点击后生成**: "我想查看数据分析报告，请帮我分析招聘数据"

## 技术实现

### 组件结构
```
CapabilityCards/
├── CapabilityCards.js          # 主组件
├── CapabilityCardsDemo.js      # 演示组件
└── test-capability-cards.js    # 测试文件
```

### 核心功能
1. **响应式布局**: 使用 Ant Design 的 Row/Col 组件实现响应式布局
2. **交互反馈**: 卡片悬停效果和点击反馈
3. **智能提示**: 根据选择的能力自动生成相应的提示信息
4. **样式定制**: 使用 styled-components 实现自定义样式

### 集成方式
在 `App.js` 中集成能力卡片组件：

```javascript
import CapabilityCards from './components/CapabilityCards';

// 在聊天界面中添加
<CapabilityCardsWrapper>
  <CapabilityCards onCapabilityClick={handleCapabilityClick} />
</CapabilityCardsWrapper>
```

## 使用方法

### 1. 基本使用
用户进入"与 Moirai 对话"页面后，会在顶部看到能力卡片展示区域。

### 2. 选择功能
点击任意能力卡片，系统会：
- 自动生成相应的提示信息
- 将提示信息填充到输入框
- 显示确认消息

### 3. 发送消息
用户可以直接发送生成的提示信息，或根据需要进行修改后发送。

## 样式特点

### 设计风格
- **现代化**: 采用卡片式设计，视觉效果清晰
- **交互友好**: 悬停效果和点击反馈
- **色彩丰富**: 每个能力卡片使用不同的主题色
- **响应式**: 适配不同屏幕尺寸

### 颜色方案
- 智能寻聘: #1890ff (蓝色)
- 简历推荐: #52c41a (绿色)
- 知识检索: #fa8c16 (橙色)
- 数据分析: #eb2f96 (粉色)

## 扩展性

### 添加新能力
1. 在 `capabilities` 数组中添加新的能力对象
2. 在 `handleCapabilityClick` 函数中添加对应的处理逻辑
3. 更新样式和图标

### 自定义样式
可以通过修改 `styled-components` 来自定义：
- 卡片样式
- 颜色方案
- 布局方式
- 交互效果

## 注意事项

1. **性能优化**: 能力卡片组件使用 React.memo 优化渲染性能
2. **可访问性**: 确保键盘导航和屏幕阅读器支持
3. **国际化**: 支持多语言文本配置
4. **错误处理**: 处理点击事件异常情况
