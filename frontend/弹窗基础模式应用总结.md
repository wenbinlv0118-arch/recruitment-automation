## 🎨 布局规范

### 宽度计算
```css
/* 弹窗出现时 */
width: calc(100% - 256px - 33.33%);

/* 弹窗未出现时 */
width: calc(100% - 256px);
```

### 三部分布局
- **左侧**: 导航栏 (256px 固定宽度)
- **中间**: 主要内容区域 (动态宽度)
- **右侧**: 弹窗区域 (33.33% 宽度)

### 动画效果
- **缓动函数**: `cubic-bezier(0.25, 0.46, 0.45, 0.94)`
- **动画时长**: 0.4s (主要动画) / 0.25s (交互动画)
- **进入动画**: 内容从右侧滑入，渐进式延迟

## 📝 使用指南

### 添加新的弹窗
```jsx
import ModalBasePattern from './components/ModalBasePattern';

<ModalBasePattern
  visible={visible}
  onClose={() => setVisible(false)}
  title="弹窗标题"
  dataAttribute="unique-identifier"
>
  <div>弹窗内容</div>
</ModalBasePattern>
```

### 主应用集成
```jsx
// 在App.js中添加状态
const hasAnyModal = recommendationVisible || otherModalVisible;

// 传递给布局组件
<StyledHeader hasModal={hasAnyModal}>
<StyledContent hasModal={hasAnyModal}>
<InputContainer hasModal={hasAnyModal}>
```
