## 🎨 核心特性

### 布局结构
- **左侧**: 导航栏 (256px 固定宽度)
- **中间**: 主要内容区域 (动态宽度，弹窗出现时被压缩)
- **右侧**: 弹窗区域 (33.33% 宽度)

### 动画效果
- **滑入/滑出**: `cubic-bezier(0.25, 0.46, 0.45, 0.94)` 缓动函数
- **动画时长**: 0.4s (主要动画) / 0.25s (交互动画)
- **进入动画**: 内容从右侧滑入，渐进式延迟
- **悬停效果**: 卡片轻微上移，按钮缩放反馈

### 性能优化
- `will-change` 属性优化动画性能
- `transform` 而非改变位置属性
- `backface-visibility` 和 `perspective` 优化3D变换

## 🔧 使用方法

### 基础用法
```jsx
import ModalBasePattern from './components/ModalBasePattern';

<ModalBasePattern
  visible={visible}
  onClose={() => setVisible(false)}
  title="弹窗标题"
>
  <div>弹窗内容</div>
</ModalBasePattern>
```

### 主应用集成
```jsx
// 头部样式

  width: ${props => props.hasModal ? 'calc(100% - 256px - 33.33%)' : 'calc(100% - 256px)'};

  will-change: width;
```

## 📋 组件API

### ModalBasePattern Props
| 属性 | 类型 | 默认值 | 描述 |
|------|------|--------|------|
| visible | boolean | false | 控制弹窗显示/隐藏 |
| onClose | function | - | 关闭弹窗的回调函数 |
| title | string | - | 弹窗标题 |
| children | ReactNode | - | 弹窗内容 |
| dataAttribute | string | "base-drawer" | 用于DOM查询的data属性 |

### 导出的样式组件
- `BaseDrawer`: 主容器
- `BaseDrawerHeader`: 头部区域
- `BaseDrawerTitle`: 标题组件
- `BaseCloseButton`: 关闭按钮
- `BaseDrawerBody`: 内容区域
- `BaseCard`: 基础卡片样式
- `BaseActionButton`: 基础操作按钮

## 🎨 样式规范

### 动画参数
```css
/* 主要动画 */
transition: transform 0.4s cubic-bezier(0.25, 0.46, 0.45, 0.94);

/* 交互动画 */
transition: all 0.25s cubic-bezier(0.25, 0.46, 0.45, 0.94);

/* 进入动画 */
@keyframes slideInFromRight {
  from {
    opacity: 0;
    transform: translateX(50px) scale(0.95);
  }
  to {
    opacity: 1;
    transform: translateX(0) scale(1);
  }
}
```

### 布局参数
```css
/* 弹窗宽度 */
width: 33.33%;

/* 中间内容区域宽度 */
width: calc(100% - 256px - 33.33%);

/* 左侧导航栏宽度 */
width: 256px;
```

## 💡 最佳实践

1. **状态管理**: 确保正确传递 `hasModal` 属性给主应用组件
2. **内容组织**: 使用 `BaseCard` 包装主要内容，使用 `BaseActionButton` 创建操作按钮
3. **性能优化**: 避免在弹窗内容中使用大量DOM元素
4. **动画效果**: 内容会自动应用进入动画，无需手动处理

## 📝 关键要点

1. **左侧导航栏保持激活状态** - 用户可以继续操作导航
2. **中间内容区域动态压缩** - 宽度从 `calc(100% - 256px)` 变为 `calc(100% - 256px - 33.33%)`
3. **右侧弹窗独立显示** - 宽度为 33.33%，带有流畅的滑入/滑出动画
4. **渐进式内容动画** - 弹窗内容按顺序出现，每个元素延迟 0.1s
5. **性能优化** - 使用CSS硬件加速和优化属性
